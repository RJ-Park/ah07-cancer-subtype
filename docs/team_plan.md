## 4. 협업 규칙

1. **자기 폴더만 수정**해요. `.ipynb`는 둘이 같은 파일을 고치면 합칠 수 없어요.
2. **`src/`는 담당자만 수정**하고, 바꾸면 디스코드에 알려요.
3. **피처는 검증된 것만** `src/features.py`로 옮겨요 (`run_cv()` 점수가 오른 것만).
4. 실험 결과는 `log_result()`로 **자기 기록표**(`experiments/log_이니셜_역할.csv`)에 남겨요.
5. 제출하고 싶은 후보는 **CV 점수와 함께 팀장에게** 알려요.
6. AI로 코드를 짤 때는 **`AI_RULES.md`를 먼저 붙여넣어요.** train과 test를 합치는 코드는 쓰지 않아요.
7. 이전 대회(특히 2024년 같은 주제 대회)나 공개 코드는 참고하지 않아요. 외부 데이터는 쓰지 않아요.

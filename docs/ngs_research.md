## 2. 주요 유전체 변이 유형
| 변이 유형 | 표기 예시 | 의미 |
| :--- | :--- | :--- |
| 미스센스 (Missense) | `R132H`, `V600E` | 아미노산이 다른 아미노산으로 바뀜 |
| 동의 변이 (Synonymous) | `D623D`, `L42L` | DNA가 변했지만 아미노산은 동일 |
| 넌센스 (Nonsense) | `R213*`, `E237*` | 종결 코돈이 생겨 단백질 합성이 조기에 종료될 수 있음 |
| 프레임시프트 (Frameshift) | `K16fs`, `L1854fs` | 삽입·결실로 단백질 번역의 읽기 틀이 바뀜 |
| 인프레임 결실 (In-frame deletion) | `E746_A750del` | 읽기 틀을 유지하면서 아미노산이 삭제됨 |
| 인프레임 삽입 (In-frame insertion) | `A767_V769dup` | 읽기 틀을 유지하면서 아미노산이 추가됨 |
| 중복 (Duplication) | `A767_V769dup` | 특정 서열이 반복됨 |
| 스플라이스 변이 (Splice-site) | `c.1903+1G>A` | RNA 스플라이싱에 영향을 줄 수 있음 |
| 시작 코돈 변이 (Start-loss) | `M1?` | 단백질 번역 시작에 영향을 줄 수 있음 |
| 종결 코돈 소실 (Stop-loss) | `*110Qext*17` | 기존 종결 코돈이 사라져 단백질이 연장될 수 있음 |
| 유전자 융합 (Gene fusion) | `BCR::ABL1` | 서로 다른 유전자가 연결됨 |
| 복제수 변이 (CNV) | `ERBB2 amplification` | 유전자 복제수가 증가하거나 감소함 |
| 기타/미분류 | 위 규칙에 해당하지 않는 경우 | 별도 확인 필요 |


- 변이 하지 않은 경우 WT(Wild Type)로 표기함.
- 한 유전자에 여러 변이가 기록된 경우 공백으로 구분함.  ex) `R273C R248Q`

### 3-2. 주의할 점
1. **유전자 이름과 실제 변이 유형 구분:** `TP53` 컬럼에 `R175H`가 있으면 단백질 수준 변이로 해석할 수 있지만, `TP53`의 발현 증가나 유전자 결실 여부를 알 수 있는 것은 아니다.
2. **암종별 유전자 목록을 정답 규칙으로 사용하지 않기:** `TP53`처럼 여러 암종에 공통으로 나타나는 유전자가 많다. 대표 유전자에 변이가 있다고 해당 암종이라고 단정할 수 없다.
3. **표본에서 학습한 암종별 변이 빈도는 교차검증 폴드 안에서 계산:** 전체 학습 데이터의 `SUBCLASS`를 이용해 유전자별 암종 특이성을 산출한 뒤 검증 폴드에 그대로 적용하면 데이터 누수가 발생할 수 있다.
4. **외부 문헌 기반 후보 유전자 집합은 사전 정의 가능:** 단, 외부 연구와 해커톤 데이터의 환자·검체 중복 여부, 데이터 출처, 유전자 측정 범위가 다를 수 있다는 점을 확인한다.
5. **동의 변이와 기능 변화 변이를 구분해 실험:** `R895R`처럼 아미노산이 바뀌지 않는 변이를 단순 변이 존재와 구분한 파생변수는 실험해 볼 수 있다. 단백질 표기만으로 실제 기능적 영향이 확정되는 것은 아니다.
6. **원본 데이터에 없는 변이 종류는 만들지 않기:** 복제수 변화(CNV), 발현량, 유전자 융합, 프로모터 변이는 해당 측정값이 없으면 직접적인 피처로 사용할 수 없다.
7. 위 표는 NCI 요약에 언급된 유전자 중심의 선별된 예시이며 각 암종의 전체 드라이버 유전자 목록이나 임상 진단 기준이 아니다. 일부 유전자명은 현행 기호로 보완 표기했다(AMER1/WTX, VSIR/VISTA).

### 1. 데이터 분석에서 확인한 내용

- 학습 데이터는 **6,201개 샘플, 4,384개 유전자 관련 컬럼, 26개 암종(SUBCLASS)**으로 구성됨.
- 유전자별 값은 `WT`, 결측치, `R132H`와 같은 변이 문자열로 구성됨.
- 하나의 셀에 여러 변이가 공백으로 구분되어 기록된 경우가 있어, 변이 유전자 수와 실제 변이 개수는 다를 수 있음.
- 변이 문자열에서 Missense, Synonymous, Nonsense, Frameshift 등의 유형을 구분할 수 있는 패턴 확인.
- 동일한 아미노산 치환 쌍(예: `R>H`, `E>K`)이 여러 유전자에서 반복적으로 나타날 수 있음을 확인함.

### 2. 피처 생성 및 실험

동일한 XGBoost 모델과 Stratified 5-Fold 교차검증을 사용하여 총 8개 피처 구성을 비교함.

| 구분 | 피처 구성 |
| :--- | :--- |
| **A (빈도 ≥5)** | 유전자명과 개별 변이 문자열을 결합한 Multi-Hot 인코딩 |
| **A (빈도 ≥3)** | A 방식에서 최소 출현 인원 기준을 3명으로 변경 |
| **B** | `WT`·결측치 = 0, 변이 존재 = 1로 이진 인코딩 |
| **C** | B + 샘플별 변이 유전자 수 (`n_mutated_genes`) |
| **D** | C + 변이 유형별 개수 5개 (`n_missense`, `n_synonymous`, `n_nonsense`, `n_frameshift`, `n_other`) |
| **D + Multi-Hot (빈도 ≥5)** | D 피처와 Multi-Hot 피처 결합 |
| **D + Multi-Hot (빈도 ≥3)** | D 피처와 Multi-Hot 피처 결합, 최소 출현 인원 3명 |
| **D + 아미노산 치환 쌍 (빈도 ≥16)** | D 피처 + 환자별 아미노산 치환 쌍 발생 횟수에 `log1p()` 적용 |

**주요 전처리 및 피처 생성 기준**

- 변이 유형별 개수는 셀 내부의 개별 변이 문자열을 분리하여 집계함.
- A 방식은 셀 전체 문자열을 하나의 범주로 처리하지 않고, 유전자와 개별 변이의 조합을 기준으로 Multi-Hot 인코딩함.
- 아미노산 치환 쌍은 `R132H → R>H`와 같이 변환하여 환자별 발생 횟수를 계산함.
- 아미노산 치환 쌍 피처에서는 동일 아미노산으로의 변이 및 종결 변이(`*`)를 제외함.
- Multi-Hot과 아미노산 치환 쌍의 출현 빈도 기준은 **각 학습 Fold 내부에서만 계산**하여 피처 선택 과정의 데이터 누수를 방지함.

| C 변이 유전자 수 추가 | 0.3663 | 0.0093 |
| D 변이 유형별 개수 추가 | 0.3836 | 0.0028 |
| D + Multi-Hot (빈도 ≥5) | 0.3867 | 0.0164 |
| D + Multi-Hot (빈도 ≥3) | 0.3851 | 0.0153 |
| **D + 아미노산 치환 쌍 (빈도 ≥16)** | **0.4271** | **0.0192** |

**주요 결과**

- B → C → D 순으로 피처를 확장하면서 Macro F1이 **0.3200 → 0.3663 → 0.3836**으로 개선됨.
- A Multi-Hot 단독은 0.1590~0.1630으로, 이진 인코딩 기반 피처보다 낮은 성능을 보임.
- D + Multi-Hot은 D 단독 대비 소폭 개선되었으나, Fold별 성능 변동이 증가함.
- **D + 아미노산 치환 쌍은 Macro F1 0.4271로 전체 8개 실험 중 가장 높은 평균 성능을 기록함.**
- D 단독 대비 **+0.0435**, 기존 최고 성능인 D + Multi-Hot (빈도 ≥5) 대비 **+0.0404** 개선됨.

### 4. 최종 피처 선정 및 모델 담당 참고사항

**최종 선정: D + 아미노산 치환 쌍 (최소 출현 인원 16명)**

- 기존 D 피처 4,390개에 아미노산 치환 쌍 피처를 추가하는 방식임.
- 첫 번째 학습 Fold 기준 치환 쌍 158개가 선택되어 총 4,548개 피처가 생성됨.
- 치환 쌍은 학습 Fold에서 16명 이상에게 나타난 경우에만 선택하며, 환자별 발생 횟수에 `log1p()`를 적용함.
- XGBoost 5-Fold CV에서 Macro F1 **0.4271 ± 0.0192**를 기록하여 현재 실험 중 최고 평균 성능을 보임.
- 다만 D 단독(표준편차 0.0028)보다 Fold별 성능 변동이 크므로, 모델별 성능과 안정성을 추가 비교할 필요가 있음.
- D 단독도 비교용 피처 구성으로 유지하는 것을 권장함.

**모델 담당 참고사항**

- 아미노산 치환 쌍 피처의 성능 개선이 다른 모델에서도 재현되는지 확인할 가치가 있음.
- 기존 8개 실험의 OOF 및 test 예측 확률을 저장하여 앙상블 검증에 활용할 수 있도록 준비함.
- 최종 성능 비교 및 실험 과정은 `notebooks/H_data/02_features.ipynb`, 실험 로그는 `experiments/log_H_data.csv`에 기록함.

### 5. 추가 참고 및 주의사항

- 변이 유형은 문자열 패턴 기반으로 분류했으므로 실제 생물학적 기능을 완벽히 판정하는 방식은 아님.
- 아미노산 치환 쌍은 단백질 수준의 치환 정보이며, 염기서열 기반 돌연변이 시그니처(SBS 등)와 동일한 개념은 아님.
- Multi-Hot 및 아미노산 치환 쌍 피처의 최소 출현 인원 기준은 학습 Fold 내부에서 결정해야 하며, 전체 train 또는 test 데이터를 사용하여 피처를 선택해서는 안 됨.
- 현재 성능은 교차검증 결과이며, 별도 검증 데이터에서 동일한 성능 개선이 나타난다는 보장은 없음.
- 변이 유형별 개수 생성 함수 `mutation_type_counts()`는 `src/features.py`에 추가했으며, 아미노산 치환 쌍 실험 구현은 `02_features.ipynb`에 정리함.

# submit/ — 최종 제출용 통합 파일 (④ 담당)

최종 코드는 **파일 하나**(.py 또는 .ipynb)로 제출해요. 이 폴더에 그 파일 하나만 둬요.

통합 파일 요건 (대회 공지 기준)
- 데이터 입출력 경로 `/data`
- UTF-8, 라이브러리 로딩부터 끝까지 오류 없이 실행
- 주석으로 전체 과정 정리, `src/` 함수도 파일 안에 직접 넣기 (파일 하나로 실행돼야 해요, `src/config.py`의 `DATA_DIR`은 `/data`로)
- 개발 환경(OS), 라이브러리 버전, Random Seed, 하이퍼파라미터 기재
- 추론에 쓴 모델 파일 다운로드 링크, 사전학습 모델을 썼다면 논문 링크

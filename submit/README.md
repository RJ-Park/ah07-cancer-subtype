# submit/ — 최종 제출 코드 (통합: ④ 박유정, 최종 확인: ① 장성은)

최종 코드는 **파일 하나**로 제출해요 → `final_solution.ipynb`

## 사용법
- 파일 안에 담당자별 칸이 있어요. **자기 칸에만** 최종 코드를 넣어요.
  - 【② 피처】 홍시윤: `src/preprocessing.py`, `src/features.py` 최종본을 붙여 넣기 (화 12시 확정 후)
  - 【③ 모델】 안주형: 최종 모델과 하이퍼파라미터 (숫자로)
  - 【④ 경량·앙상블】 박유정: 모델 결합 방식과 가중치
- 현재 최종본: 데이콘 24번(LB 0.43631) 구성. 11번 구성 3모델 평균 + 쌍 2단계 판정(`USE_PAIR_TWO_STAGE = True`).
- 로컬에서 시험할 때는 환경변수 `DATA_DIR`에 data 폴더 경로를 넣어요. 제출본의 기본값은 `/data`예요.

## 제출 요건 (대회 공지)
- [ ] 데이터 입출력 경로 `/data`
- [ ] UTF-8, 라이브러리 로딩부터 끝까지 오류 없이 실행 (새 Colab에서 확인)
- [ ] 주석으로 전체 과정 정리, `src/` 함수는 파일 안에 직접 포함
- [ ] 개발 환경(OS), 라이브러리 버전, Random Seed, 하이퍼파라미터 기재 (파일 맨 위 표)
- [ ] 추론에 쓴 모델 파일 다운로드 링크
- [ ] 사전학습 모델을 썼다면 논문 링크와 출처
